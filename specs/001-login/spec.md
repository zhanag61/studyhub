## 目标与使用场景

作为已有测试账号的学习者，我希望用用户名和密码进入自己的工作台，确认当前身份，并在使用后退出。没有登录的人可以浏览公开首页，但不能打开个人页面。

这一轮用最小个人欢迎页验证登录能力。学习计划、任务和进度仍在后续阶段实现，不用提前生成这些功能来演示登录。

## 需求决定与状态

| 决定 | 状态 | 内容 |
|---|---|---|
| 登录方式 | 原路线已确认 | 用户名和密码，使用预先建立的测试账号 |
| 登录后的目的地（Q1） | 用户已确认 | 进入「我的工作台」，显示当前用户名与退出按钮 |
| 基础流程（Q2） | 用户已确认 | 采用空输入、统一错误提示、未登录跳转、退出回公开首页的推荐行为 |
| 登录有效期（Q3） | 用户已确认 | 登录保留 7 天，不增加「记住我」选项；主动退出立即结束这次登录 |
| 完整规范 | 用户已确认 | 用户回复「确认这份规范（推荐）」；下一课先写技术计划与任务 |

以下验收例子是双方确认的行为约定；不是已经实现或验收的结果。

## 本轮范围

- 公开首页提供登录入口；原欢迎内容继续供未登录的人查看。
- 登录页输入用户名、密码，密码输入不直接显示明文。
- 正确登录后进入「我的工作台」，例如账号 learner_a 显示「你好，learner_a」和退出按钮。
- 工作台只显示当前账号身份与功能待开放说明，不显示其他用户列表或预先添加业务模块。
- 错误与空输入留在登录页，用户能知道怎样修正。
- 未登录打开工作台先进入登录页；本轮登录成功统一进入「我的工作台」。
- 点击退出回公开首页，此后刷新或重新访问工作台须再次登录。
- 从本次成功登录起保留最多 7 天；刷新、打开新标签页、正常关闭并重新打开浏览器不要求重复登录，浏览操作不会把期限重新计为 7 天。主动退出立即结束当前浏览器的这次登录；再次成功登录开始新的 7 天。
- 同一浏览器中的标签页共用这次登录；两个账号的验收用两个独立浏览器会话，避免把共用会话误当成身份串用。
- 电脑和手机浏览器都能输入、查看提示和操作退出。

## 验收例子（实现后逐条验证）

| 编号 | 前提与操作 | 预期结果 |
|---|---|---|
| A001 | 未登录，打开公开首页 | 正常显示 M0 欢迎内容，可以找到登录入口 |
| A002 | 点击登录入口 | 看到用户名、密码与登录按钮；没有注册或找回密码入口 |
| A003 | 测试账号 learner_a 输入正确密码并提交 | 进入「我的工作台」，显示「你好，learner_a」与退出按钮 |
| A004 | learner_a 输入错误密码，或输入不存在的用户名 | 留在登录页，统一提示「用户名或密码不正确」；保留用户名，清空密码框，不显示其他账号是否存在 |
| A005 | 用户名或密码为空并提交 | 留在登录页，明确指出未填写的字段；不能获得登录状态 |
| A006 | 未登录，直接打开工作台地址 | 先进入登录页，不能看到个人页面；正确登录后进入工作台 |
| A007 | learner_a 已登录且尚未过期，刷新工作台、打开新标签页或正常关闭并重开浏览器 | 仍显示 learner_a，无须重新输入密码 |
| A008 | 在另一独立浏览器会话用 learner_b 登录 | 该会话显示 learner_b；原 learner_a 会话仍显示 learner_a |
| A009 | learner_a 点击退出，再刷新或直接打开工作台；在同一浏览器其他标签页重新请求工作台 | 退出时回公开首页，随后个人页面访问先进入登录页；这次旧登录状态失效，其他标签页不能继续用它取得个人页面 |
| A010 | 已登录，再打开登录页 | 进入「我的工作台」，不要求重复输入凭据 |
| A011 | 使用带外部网站跳转目的地的登录入口 | 登录后仍进入本系统工作台，不跳到外部网站 |
| A012 | 从本次成功登录起达到 7 天后再次访问工作台 | 先进入登录页，即使此前有浏览操作也不能延长期限；重新登录开始新的 7 天 |
| A013 | 在手机上完成登录、查看工作台与退出 | 输入框、提示和按钮可用，核心操作不依赖横向滚动 |

所有例子当前均未运行。7 天有效期在实现阶段用可控时间验证，不要求用户等待一周才能验收；页面行为再由用户在浏览器操作确认。

## 数据与身份边界

测试账号预先准备，实际密码不写入规范、公开提交或 PR。工作台身份来自有效登录状态，不能通过修改网址或表单中的用户名冒充另一个账号。无登录状态时，服务端不得返回受保护的个人内容。

本轮尚无计划、任务或笔记数据，不能将个人欢迎页验收扩大为 M4 的业务数据权限验收。服务重启与部署不应意外破坏仍有效的登录状态；具体持久配置由 M1-L02 技术计划处理。

注册、邀请码、邮件找回、社交登录、修改个人资料、管理员业务界面、跨设备全部退出、并发登录控制、学习计划、任务、笔记、搜索、统计，以及邀请真实测试者使用。按路线在相应阶段另做规范。
