# M0 技术计划

Python 3.13 + Django 5.2.17，依赖安装在项目内 `.venv` 并锁定到 requirements.txt。

网址规则连接 Python 视图与 Django HTML 模板；视图传递可供初学者修改的欢迎文案。CSS 和图标本地提供，不依赖外部字体或图片服务。

本地使用 SQLite，初始化 Django 内置迁移。当前首页不保存用户数据；账号与业务模型在后续课程添加。

开发时没有固定密钥就生成临时随机密钥，M1 接入登录前再配置持久本地密钥；关闭 DEBUG 时缺少环境密钥会明确报错。M4 再完成生产数据库与部署配置。

本地初始化 main 基线，后续练习使用功能分支。准备只读权限的 GitHub Actions 配置，先检查配置和迁移一致性；功能测试随 M1 的实际行为加入。

按 2026-10-08 教学调整，Agent 默认执行分支、差异检查、提交与排错；用户通过聊天限定范围并验收。命令示例供选学，不再将逐条手工执行作为继续课程的前提。

课程文件与规范一同进入仓库；日志必须区分准备完成、自动检查通过、用户手工验收与线上验证。
