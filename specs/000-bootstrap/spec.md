# 000：M0 起步准备规范

来源：用户已确认并请求实施的 StudyHub 教学路线。

## 目标

建立独立、可启动、可保存版本的项目，并提供能接续教学的课程记录。当前交付围绕 M0 本地准备；后续业务功能按课程推进。

## 场景与验收

1. 使用本项目虚拟环境启动 Django 后，浏览器能打开欢迎首页。
2. 首页显示真实的起步状态，尚未实现的业务功能标为即将开放。
3. 在新分支修改 `WELCOME_MESSAGE` 后，浏览器刷新显示新文字，Git 能显示对应差异。
4. 仓库提供 M0–M8 课程表、每步聊天指令、终端操作解释与课程日志。
5. Git 忽略虚拟环境、SQLite、密钥与备份；本地建立 main 初始化基线。
6. Agent 检查与用户亲手验收分别记录；未完成的 GitHub、线上发布及业务课程保持待办。

## 当前不包含

账号注册与登录、学习计划、任务进度、笔记、资料、标签、搜索及统计的业务实现。它们按已确认课程推进，当前首页不能声称已经可用。

## M0-L01 用户反馈：欢迎页的温度与区域区分

用户已确认浏览器显示首页及主标题，并要求调整两处体验：

- 工作台标题采用「在这里，收好你的每一点进步。」；替换生硬的「一个地方」表述。
- 欢迎区、步骤区、工作台与卡片使用不同的低饱和背景色；正文保持清晰，电脑和手机宽度均无横向溢出。
- Python 中的主标题留给用户亲手修改；Agent 的界面示范和用户的文案练习分别记录。

## GitHub 与部署验收

在后续 M0-L03 和 M0-L04 真实建立远端与线上地址；本地完成不等于整个 M0 已验收。需要实际用户网络和账户操作时保留对应课程待办。

## 2026-10-08 教学方式调整

用户要求以 vibe coding 为主，由 Agent 接手 Git 与排错。用户通过聊天表达需求、确认规范、验收页面；Agent 执行实现、分支、检查和提交，解释结果。终端命令练习为选学。用户操作与 Agent 代办分别记录，不把完成提交写成用户已经掌握命令。
