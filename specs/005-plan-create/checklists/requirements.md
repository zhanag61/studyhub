## Content Quality

- [x] 不含实现方案、框架选择、接口设计或数据库结构。
- [x] 聚焦学习者保存本人学习目标的价值。

## Requirement Completeness

- [x] 无 NEEDS CLARIFICATION 标记，关键选择来自用户回答，其余默认值明确待审阅。
- [x] 标题/说明长度、空白、日期规则与提示可验证，无模糊的“合理输入”。
- [x] 成功条件使用保存数量、内容、账号归属及页面操作等可测结果。
- [x] 成功条件不依赖某种技术实现。
- [x] 正常创建、选填组合、同名、取消、错误和身份场景均已定义。
- [x] 覆盖空白、越界、无效/过去日期、跨午夜、刷新、过期与失败等边界。
- [x] 创建与必要卡片展示范围清楚，后续编辑/删除/任务等排除明确。
- [x] 依赖已有登录规则；北京时间、长度与展示等默认值已列出。
