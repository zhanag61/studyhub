## 浏览器操作与预期

1. 未登录访问创建页先登录；正常登录后仍回工作台，再点击「创建学习计划」。
2. A 填 Python 入门、每天练习20分钟、未来一周日期；提交后回工作台，提示计划已创建和新卡片。
3. 再只填标题保存，说明为空，卡片为未设置目标日期；主动同名创建得到另一个独立卡片。
4. 空/空白标题、100/101 字符、1000/1001 字符、无效/过去/当天日期按规范核对。
   标题达100个有效字符时仍可带首尾空白输入；错误保留可恢复的内容，修正后只新增一份。
5. 用独立 B 会话查看，不能见 A 的标题/说明/日期；B 同名计划只属于 B。
6. A 刷新、退出重登，记录和数量不变；切换 B 后不取得 A 卡片，取消也不新增。
7. 手机填表、看提示、取消/创建和卡片，无横向滚动；旧 8002 已停止，届时按实时网络重新准备。

用户只反馈页面现象，不发送密码。用脚本模拟 320/390px 不替代实际手机反馈。

## 自动检查需要的证据

- 一次性数据库中的四种选填组合、同名独立身份、稳定排序、日期/文本边界与普通文字转义。
- 两个 Client 的本人读取、伪造 owner/id 不更新旧记录、过期/退出/匿名不能写、启用真实 CSRF 检查。
- 实际 INSERT 后触发明确数据库异常，核对回滚和无成功消息；确认绑定输入仍在。
- 原 M1 会话/登录回归；必要时更新纯文案断言，不放宽认证行为。
