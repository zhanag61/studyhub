# M0-L01：亲手启动第一个页面

## 本课目标

你能启动 StudyHub，在浏览器看到首页；能在功能分支修改一句文案，并解释这个过程。Agent 已准备好项目环境，手工练习仍由你完成。

## 概念：虚拟环境

`.venv` 是这个项目自己的 Python 工具箱。它保存 Django 和相关依赖。明确调用其中的 Python，就能让不同项目使用各自的工具版本。

## 第一步：进入项目

输入 **PowerShell**：

```powershell
Set-Location 'D:\developer\studyhub'
.\.venv\Scripts\python.exe --version
.\.venv\Scripts\python.exe -m django --version
```

`Set-Location` 切换工作目录；后两条确认本项目使用的 Python 和 Django。预期分别为 Python 3.13.x、Django 5.2.17。

把输出发到聊天：

> 我完成 M0-L01 第一步，版本输出如下：[输出]。请确认后带我启动页面。

## 第二步：启动页面

```powershell
.\.venv\Scripts\python.exe manage.py runserver
```

`manage.py` 是本项目的管理入口；`runserver` 启动本地开发服务器。看到服务器地址后，保持这个终端运行，在浏览器打开：

<http://127.0.0.1:8000/>

预期看到 StudyHub，主标题是「今天，从一个小目标开始。」，“认识你的工作台”会滚动到下方卡片。业务功能目前显示“即将开放”。

把结果发到聊天：

> 我已看到 StudyHub 首页，主标题是「今天，从一个小目标开始。」。请解释页面从 Python 到浏览器的过程，并带我做文案练习。

如果端口被占用，先把完整报错发给 Agent；不要结束不认识的进程。按 `Ctrl+C` 可停止你自己启动的服务器。

## 第三步：理解请求流程

浏览器向 `/` 发请求。网址规则找到 `core.views.home`，函数把 `WELCOME_MESSAGE` 交给 HTML 模板，模板生成页面返回浏览器。

试着用自己的话解释：Python 为什么能改变网页里的文字？Agent 根据你的解释补充。

## 第四步：在分支上改一句话

另开一个 PowerShell 窗口，保持服务器继续运行：

```powershell
Set-Location 'D:\developer\studyhub'
git status
git switch -c feat/m0-welcome-message
```

`git status` 查看当前工作状态；`git switch -c` 从当前版本创建并进入新分支。若显示已有修改或分支已存在，先把结果发给 Agent 安排下一步。

打开 `core/views.py`，只改变下面引号内的文字：

```python
WELCOME_MESSAGE = "今天，从一个小目标开始。"
```

例如换成「我正在用 Python 建立自己的学习工作台。」。保存文件，等待服务器自动重新加载，再刷新浏览器。

```powershell
git diff -- core/views.py
```

`git diff` 展示还没提交的改动。解释显示的旧文字和新文字，不在本课提交其他文件。
