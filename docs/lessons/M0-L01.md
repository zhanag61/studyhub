## 概念：虚拟环境

`.venv` 是这个项目自己的 Python 工具箱。它保存 Django 和相关依赖。明确调用其中的 Python，就能让不同项目使用各自的工具版本。

## 第一步：进入项目

输入 **PowerShell**：

```powershell
Set-Location 'D:\developer\studyhub'
.\.venv\Scripts\python.exe --version
.\.venv\Scripts\python.exe -m django --version
```

`Set-Location` 切换工作目录；后两条确认本项目使用的 Python 和 Django。预期分别为 Python 3.13.x、Django 5.2.17。

## 第二步：启动页面

```powershell

```

`manage.py` 是本项目的管理入口；`runserver` 启动本地开发服务器。看到服务器地址后，保持这个终端运行，在浏览器打开：

## 第三步：理解请求流程

浏览器向 `/` 发请求。网址规则找到 `core.views.home`，函数把 `WELCOME_MESSAGE` 交给 HTML 模板，模板生成页面返回浏览器。

具体可以按这条链路阅读：

`浏览器 GET / → config/urls.py → core/urls.py → core/views.py 的 home() → core/home.html → 返回 HTML → 浏览器加载 CSS 显示页面。`

```python
WELCOME_MESSAGE = "今天，从一个小目标开始。"

def home(request):
    return render(request, "core/home.html", {"welcome_message": WELCOME_MESSAGE})
```

`request` 是浏览器带来的请求；字典把 Python 文案用 `welcome_message` 这个名字交给模板。模板中的 `{{ welcome_message }}` 会被替换成那句文字。

本次 Agent 示例把工作台标题改为「在这里，收好你的每一点进步。」，并用雾蓝、浅杏、浅绿等低饱和色区分区域。这些分别来自 HTML 文案和 CSS 样式。你接下来修改 Python 中的主标题，体验三种文件各自的作用。

## 第四步：在分支上改一句话

另开一个 PowerShell 窗口，保持服务器继续运行。本次 Agent 已示范创建并进入 `feat/m0-welcome-message` 分支，你先核对：

```powershell
Set-Location 'D:\developer\studyhub'
git status
git branch --show-current
```

`git status` 查看当前工作状态；`git branch --show-current` 显示当前分支，预期为 `feat/m0-welcome-message`。你会看到 Agent 这次示范留下的 HTML、CSS、规范和课程记录修改，下一课会与个人练习分开提交。

创建分支用的命令是 `git switch -c feat/m0-welcome-message`，其中 `-c` 表示创建。本次已经执行，不要重复创建同名分支。

打开 `core/views.py`，只改变下面引号内的文字：


`git diff` 展示还没提交的改动。这里指定 `core/views.py`，所以只看你的 Python 文案修改。解释显示的旧文字和新文字，提交练习留在下一课。
