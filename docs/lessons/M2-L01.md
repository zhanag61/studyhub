# M2-L01：让工具协助管理规范

2026-10-14，本课完成 Spec Kit 工具准备，关联 [Issue #9](https://github.com/zhanag61/studyhub/issues/9)。安装、文件、Git 和检查由 Agent 执行；你无需复制安装命令。

## 本课只学一个概念

M1 时，我们手工写 spec、plan、tasks，再实现和验收。Spec Kit 把这些步骤整理成技能和模板，帮助 Agent 使用一致流程。你继续通过聊天决定“做什么”和确认“怎样算完成”；每次只调用当前步骤，看到文档与例子后再推进。

数据路径：**你的聊天需求 → Agent 读取技能与项目规则 → 仓库里的规范 → 你确认 → 技术计划与小任务 → 实现和验收**。本课只准备工具及规则，还没有新增学习计划页面或写入业务数据。

## 下一次怎样发指令

可以用自然语言说明步骤，也可以在聊天写 `$speckit-specify`。例如：

> 开始 M2-L01 规范续课。只做「创建自己的学习计划」的需求规范，先问清字段和提交后的行为，再使用 speckit-specify 生成文档并用具体例子让我确认。由你操作 Git 和文件，暂不实现代码。

课程表中的“第一轮工具规范经过确认”留到续课；工具能运行与需求已确认是不同验收。本课不推断你已掌握命令，也不提前决定标题长度、日期、列表或编辑行为。

可选聊天练习：告诉 Agent「只生成规范，不写代码」，观察是否守住范围。技能映射与选学终端命令见 [Spec Kit 指南](../SPECKIT.md)。
