## 一个概念：账号与登录状态不同

账号是数据库中的一条用户记录。登录状态是浏览器通过验证后获得的身份凭证。创建账号只是让 Django 有可以验证的用户，尚不意味着浏览器已经登录，也不会自动生成登录页面。

我们准备两个身份，后续分别登录，用来检查工作台显示的确实是当前用户：

| 本地账号 | 状态 | 权限 | 后续用途 |
|---|---|---|---|
| learner_a | 启用 | 普通账号 | 第一组登录验收 |
| learner_b | 启用 | 普通账号 | 另一独立浏览器会话的身份验收 |

两个账号都不是 staff 或超级用户，没有额外权限；本轮不需要给验收者管理网站的能力。

## 本课怎样准备

1. 只读检查目标为项目中的 db.sqlite3，两个账号名未被占用。
2. 核对 Django 内置迁移已完成，没有需要应用的新迁移。
3. 使用 Django create_user 创建账号，生成不同的随机密码。Django 用户表保存密码哈希，不直接保存明文密码。[Django 官方说明](https://docs.djangoproject.com/en/5.2/topics/auth/default/#creating-users)
4. 将人工验收凭据写入本机 Git 忽略目录 `.tools/qa/local-test-accounts.json`，不打印到终端或写入提交、Issue、PR。
5. 重新读取账号和私有资料，确认凭据可验证、账号已启用且无管理权限。

脚本会拒绝非本地环境或不同数据库路径；同名已有账号只能在归属、权限和本机资料匹配时复用，不擅自改密码。新增账号与资料写入失败时回滚，并清理本次新文件。
