## 一个概念：仓库里的自动检查员

`.github/workflows/checks.yml` 规定推送到 main 或向 main 发起 PR 时执行哪些检查。每条 job 从独立运行环境取代码、装固定依赖，再依次检查；任何一步失败会使该 job 失败。两个 job 分别覆盖 SQLite 和临时 PostgreSQL，实际运行结果以后在 GitHub 的 PR「Checks」查看。[GitHub 服务容器说明](https://docs.github.com/en/actions/tutorials/use-containerized-services/create-postgresql-service-containers)

本课给两条 job 都加入 `python manage.py test core.tests --noinput`。这条命令让 Django 建立独立测试数据库，验证登录、提示、会话、期限和退出，再清理测试数据，不使用你的人工验收账号。[Django 测试说明](https://docs.djangoproject.com/en/5.2/topics/testing/overview/)

以前有配置和迁移检查，本轮让已有 51 项行为测试也进入自动流程。PostgreSQL job 保留原临时数据库，再检查配置、迁移、行为与正式部署请求；未添加线上数据库密钥或新的运行依赖。
