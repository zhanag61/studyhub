## 一个概念：退出让当前会话失效

点击「退出登录」会提交带 CSRF 的 POST 请求，Django 删除当前服务器会话并清除 Cookie，再回公开首页。旧 Cookie 即使再次发送，也不能取得个人页面；另一个独立浏览器的登录继续有效。[Django 退出说明](https://docs.djangoproject.com/en/5.2/topics/auth/default/#django.contrib.auth.views.LogoutView)

这样同一窗口可以依次执行「A 登录 → 退出 → B 登录」。不同账号同时保持登录仍用普通窗口加隐私窗口或两个浏览器；普通标签页共用当前身份。
