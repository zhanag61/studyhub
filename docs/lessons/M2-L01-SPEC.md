## 一个概念：先固定“发生什么”

“保存后回工作台，并看到新计划”是需求；“表单和数据怎样实现”留技术计划。
一个清楚的验收例子包含起点、操作和结果，能帮助你与 Agent 对同一行为形成一致预期。

例如，假设提交时为北京时间 2026-10-14：

1. A 填「Python 入门」、说明「每天练习 20 分钟」、日期 2026-10-21；成功后回工作台，显示成功提示与一张包含这些内容的卡片。刷新、退出后重新登录仍在。
2. 只填「读完一本书」也成功；日期保持未设置。空标题不保存，提示必填并保留其他输入；2026-10-13 提示日期不能早于今天。
3. A 再建「Python 入门」得到另一份计划；B 的工作台看不到 A 的两张卡片，B 的同名计划独立属于 B。

这些是待实施的验收条件，本课没有在浏览器运行它们，也不要求你测试尚未实现的页面。
